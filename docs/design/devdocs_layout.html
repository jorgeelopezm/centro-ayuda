Introduction to NexusDocs

NexusDocs is a modern, flexible, and powerful framework designed to streamline the development of scalable web applications. It provides a robust set of tools out-of-the-box, allowing you to focus on building features rather than wrestling with configuration.

Key Features

  • Lightning Fast: Built on a high-performance core architecture.
  • Type Safe: First-class support for TypeScript across all layers.
  • Modular: Only import what you need. Keep your bundle size small.
  • Developer Experience: Intuitive API, excellent error messages, and hot module replacement.

How it works

The framework uses a unidirectional data flow combined with a reactive virtual DOM. When state changes, only the affected components are intelligently re-rendered. This ensures optimal performance even in complex data grids or dashboards.

Prerequisites

Ensure you have Node.js v16.0 or higher installed before proceeding to the installation phase.

Getting Started

Installation

Getting up and running with NexusDocs is incredibly straightforward. You can use your favorite package manager to scaffold a new project.

Creating a new project

We recommend using our CLI tool to bootstrap your application. It sets up the directory structure, configuration files, and testing framework automatically.

# Using npm
npx create-nexus-app@latest my-app

# Using yarn
yarn create nexus-app my-app

# Using pnpm
pnpm create nexus-app my-app

Manual Installation

If you prefer to integrate NexusDocs into an existing project, install the core packages directly:

npm install @nexus/core @nexus/router react react-dom

Next, configure your nexus.config.js file in the root directory:

import { defineConfig } from '@nexus/core';

export default defineConfig({
  server: {
    port: 3000,
    cors: true
  },
  plugins: []
});

API Reference

REST API Endpoints

Detailed specification of the available REST API endpoints for user management.

Method Endpoint Description
GET /api/v1/users Retrieve a paginated list of users.
POST /api/v1/users Create a new user record.
PATCH /api/v1/users/:id Update partial fields of a user.
DELETE /api/v1/users/:id Soft delete a user by ID.

Making a Request

Here is an example using `fetch` to create a new user.

const createUser = async () => {
  const response = await fetch('https://api.nexus.dev/v1/users', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer YOUR_API_KEY'
    },
    body: JSON.stringify({
      email: 'dev@example.com',
      role: 'admin'
    })
  });

  return response.json();
};
